## ✨ Key Capabilities

* **Hybrid Workflow:** Combine precise Blueprint recording with dynamic AI decision-making.
* **Spatial Mapping:** High-res layout understanding that survives UI changes.
* **LLM Agnostic:** Native support for Gemini, OpenAI, and Groq.
* **Developer First:** Built for .NET 10, extensible via C#.

## 🛠️ Quick Start

1. **Download:** Get the latest `.msi` from the [Releases](https://github.com/aetherium-ui-automation/aetherium/releases) page.
2. **Install:** Run the setup and launch `Aetherium.Win.exe`.
3. **Configure:** Enter your License Key in the **Account** tab and set your AI provider in **Settings**.
